# exercicios_C_hially
# 💻 Exercícios em Linguagem C

Este repositório reúne uma coleção de rotinas e programas práticos desenvolvidos na linguagem **C** para o fortalecimento de lógica de programação e conceitos fundamentais da linguagem.

---

## 📌 Conteúdo do Repositório

O repositório contém resoluções para diversos exercícios práticos (`exemplo01.c` até `exercicio14.c`+) focado nos seguintes conceitos[cite: 3]:

- Sintaxe básica e entrada/saída (`printf`, `scanf`)
- Estruturas condicionais (`if`, `else`, `switch`)
- Laços de repetição (`for`, `while`, `do-while`)
- Manipulação de variáveis e operadores matemáticos/lógicos
